# AI-Driven Clinical-Lifestyle Network Model for Early Prediction of Cardiovascular Diseases

## Overview
Hybrid CVD prediction system using:
- Graph Attention Network (GAT)
- XGBoost
- LightGBM
- Logistic Regression
- SHAP Explainability

## Results
- Test AUROC: 0.7089
- CV AUROC: 0.735 ± 0.028
- Sensitivity: 91.78%
